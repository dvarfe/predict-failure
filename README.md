# Predict-Failure: система предиктивного обслуживания оборудования

**Predict-Failure** — прототип платформы для мониторинга аппаратных компонентов и предсказания отказов с помощью методов анализа выживаемости.


**Краткий обзор**
- **Что делает проект**: собирает телеметрию (CPU, GPU, диски, батареи, события), хранит данные, обучает модели и выполняет прогнозы. Также предоставляет веб-интерфейс для визуализации и управления.
- **Кому это полезно**: инженерам по надежности, админам инфраструктуры, исследователям в области предиктивного обслуживания.

**Основные возможности (функционал)**
- **Сбор данных**: набор коллекторов в `collectors/` собирает метрики с различных компонентов и сохраняет их в `storage/data/`.
- **Хранение данных**: сырые CSV и предобработанные датасеты хранятся в `storage/data/`; конфигурация — в `storage/configs/`.
- **Пайплайн подготовки данных**: в `modules/` и `modules/base/` содержатся базовые классы и провайдеры данных для приведения сырых логов к формату, пригодному для обучения.
- **Хранение моделей**: `model_storage/` реализует интерфейс сохранения/загрузки ML-артефактов.
- **Инференс / Прогнозирование**: в `modules/` и `core/` находятся компоненты для применения моделей к новым данным и получения прогнозов.
- **Веб-интерфейс и визуализация**: `templates/`, `static/` и `visualization/plots.py` реализуют UI и визуальные представления прогнозов и метрик.

**Конфигурация и настройки**
- Основной конфиг: `storage/configs/config.json`.
- Параметры логирования и пути можно менять в `core/config.py`.
