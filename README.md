# Predict-Failure: Система предиктивного обслуживания оборудования

**Predict-Failure** — это распределенная микросервисная система для мониторинга состояния оборудования и предсказания отказов с использованием машинного обучения. Система построена на основе микросервисной архитектуры.

## Постановка задачи

Цель проекта — создать систему для предиктивного обслуживания IT-оборудования, которая собирает телеметрию с компьютерных компонентов (CPU, GPU, диски, батареи), анализирует их состояние и предсказывает вероятность отказа с использованием методов анализа выживаемости.

## Сценарии использования

1. **Мониторинг состояния оборудования** — непрерывный сбор данных о состоянии системных компонентов и их сохранение
2. **Обучение моделей предсказания отказов** — создание и обучение ML-моделей на основе исторических данных для прогнозирования времени до отказа оборудования  
3. **Прогнозирование отказов** — применение обученных моделей для оценки риска отказа конкретного компонента и времени до отказа
4. **Интерактивная визуализация** — просмотр динамики показателей оборудования, результатов прогнозов и построение отчетов о состоянии системы

## Микросервисная архитектура

Система состоит из следующих независимых сервисов:

### 1. **Collector Service** (сборщик данных)
- Собирает телеметрию с системных компонентов (CPU, GPU, диски, батареи)
- Реализует коллекторы для различных источников данных
- Предоставляет REST API для получения данных по запросу
- Ведет лог операций сбора данных

### 2. **Storage Service** (хранилище данных)  
- Управляет хранением сырых и обработанных данных
- Поддерживает файловое хранение

### 3. **ML Service** (платформа машинного обучения)
- Хранит ML-артефакты и модели
- Предоставляет API для обучения моделей анализа выживаемости
- Выполняет инференс для предсказания отказов

### 4. **Web Master** (главный веб-сервер)
- Единая точка входа в систему
- Маршрутизация запросов между сервисами  
- Мониторинг состояния системы

### 5. **Visualization Service** (сервис визуализации)
- Дашборды для мониторинга состояния оборудования
- Визуализация прогнозов

### 6. **System Manager** (менеджер системы)
- Координация работы всех сервисов
- Управление конфигурацией системы
- Мониторинг состояния сервисов

## Применение

- **IT-инфраструктура**: мониторинг серверов и рабочих станций, предсказание отказов оборудования
- **Промышленность**: предиктивное обслуживание промышленного оборудования
- **Исследования**: платформа для изучения методов анализа выживаемости в области надежности техники

## Конфигурация

Конфигурационные файлы находятся в директории `storage/configs/`:
- `config.json` — основная конфигурация системы
- `prototype_config.json` — конфигурация для прототипа
